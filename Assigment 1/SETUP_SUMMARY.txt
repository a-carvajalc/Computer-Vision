================================================================================
KEY FORMULAS & REFERENCE
================================================================================

THIN LENS EQUATION
  1/f = 1/s_o + 1/s_i
  m = -s_i / s_o
  f > 0: converging lens
  f < 0: diverging lens
  s_i > 0: real image
  s_i < 0: virtual image
  m < 0: inverted image
  m > 0: upright image

ROTATION MATRICES (2D)
  [[cos(θ), -sin(θ)],
   [sin(θ),  cos(θ)]]

ROTATION MATRICES (3D)
  R_x(φ), R_y(θ), R_z(η) - see LEARNING_GUIDE.md

AFFINE TRANSFORMATION
  dst = M @ [x, y, 1]^T  where M is 2×3 matrix

HOMOGRAPHY (PROJECTIVE)
  dst = normalize(H @ [x, y, 1]^T)  where H is 3×3 matrix

   - Color images are BGR not RGB
   - Use cv2.warpAffine() and cv2.warpPerspective() for transforms
